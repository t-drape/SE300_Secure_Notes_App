  If file content exists,
    Encrypt file contents from writing window, (passing password)

  Return filename


-choose_file(): SDD_TT_3_003 :: SRD::T_12, SRD::T_13, SRD::T_14
  Print message for user input,
  If file exists,
    Return filename
  Else,
    Return to start of program


-confirm_delete(): SDD_TT_3_004 :: SRD::T_20, SRD::T_43
  Print message for user input,
  If user input = confirmation,
    Return true
  Else,
    Return false


-new_note(): SDD_TT_3_005 :: SRD::T_11
  Generate filename,
  If no written content,
    Don't save file
  Else,
    Save file under filename (call save function)


-display(string file): SDD_TT_3_006 :: SRD::T_14, SRD::T_54
  file = filename,
  Get file from DB,
  Decrypt file contents and save them to a temporary file, (passing password)
  Open temporary file in read-only mode


-append(string file): SDD_TT_3_007 :: SRD::T_13
  file = filename, 
  Get file of filename from DB,
  Write decrypted file contents to temporary file, (pass password)
  Open temporary file in append mode in writing window,
  Save file (call the Save function)


-summarize(string file): SDD_TT_3_008 :: SRD::T_12
  file = filename,
  Get file of filename from DB,
  Decrypt file contents and write to a temporary file, (pass password)
  Call the AI class summary function and pass the decrypted temporary file,
  Get return value from AI summary function,
  Display returned file contents


-delete(strIng file): SDD_TT_3_009 :: SRD::T_23
  file = filename,
  Call DB delete function, passing filename parameter

        Pass file to append function
    4) Summarize Note:

    5) Delete Note:
        Call choose_file function,
        Pass file to delete function
    6) Default:
        Restart program
